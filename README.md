# 🏦 Banking Analytics & Customer Insights Dashboard

> An end-to-end data analytics project using **SQL + Power BI + DAX** to explore banking customers, accounts, transactions, and compliance-related patterns.

---

## 📌 Project Overview

This project focuses on transforming raw banking data into meaningful analytical insights using SQL and Power BI.

The project follows a complete analytics workflow:

**Raw Data → SQL Analysis → Data Transformation → Power BI Modeling → DAX → Interactive Dashboard → Business Insights**

The main goal is not just to create visualizations, but to understand the data, answer business questions, identify patterns, and present the findings through an interactive dashboard.

---

## 🎯 Project Objectives

- Analyze banking customer and account information
- Understand transaction patterns and trends
- Analyze transaction amounts and volumes
- Study account-type distribution
- Analyze customer/account characteristics
- Examine transaction status
- Analyze KYC status
- Explore state-wise banking activity
- Create meaningful KPIs using DAX
- Build an interactive Power BI dashboard
- Convert analytical findings into business insights

---

# 🎯 Business Questions

The analysis was designed around practical business questions:

- Which account types have higher transaction activity?
- How does transaction activity change over time?
- Which states show higher banking activity?
- What is the distribution of account holders?
- What proportion of transactions are successful, failed, or pending?
- How is KYC status distributed across customers?
- What are the major transaction patterns?
- Which customer or account segments show notable differences?
- What trends can be identified from transaction data?
